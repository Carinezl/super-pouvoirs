# Le calendrier des super-pouvoirs

Un calendrier de l'avent à partager entre un adulte et un enfant de 3 à 6 ans. Chaque jour, un petit jeu et une fiche pour l'adulte abordent le corps, l'intimité, le droit de dire oui ou non, les émotions et les personnes de confiance.

Le site : https://carinezl.github.io/super-pouvoirs/

Ce calendrier est une ressource de sensibilisation. Il ne se substitue pas à l'accompagnement de professionnel·les. En cas d'inquiétude pour un enfant, appelez le 119.
